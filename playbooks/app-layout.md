# App layout and spacing basics
- An 8 px spacing grid; content max width 1120 px; one primary action per screen; 44 px minimum touch targets.
- Type scale 14/16/20/28; one font family; two weights. Cards 12 px radius with a 1 px border, not heavy shadows.
- Empty, loading and error states for every list. Navigation reachable from every screen in one tap.
